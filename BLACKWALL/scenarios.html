Catalogue des Scénarios

Ce document répertorie les 5 comportements réseaux modélisés dans le simulateur BLACK WALL pour ce PFA. Il inclut le scénario "Baseline" (Trafic Normal) servant de groupe de contrôle, ainsi que 4 vecteurs d'attaque courants démontrant la polyvalence de la détection (Wazuh + Random Forest).

Scénario de Contrôle

01. Baseline — Trafic Normal d'Entreprise

ML Risk Score
02 - 15
Aucun faux positif majeur
Statut : Monitoring passif

Contexte & Comportement Réseau

Ce scénario simule l'activité légitime quotidienne des employés et services automatisés autorisés sur le réseau.

  • Fréquence très basse : ~10 à 50 événements par minute d'intérêt (login, cron, syscalls).
  • Authentifications qui réussissent au 1er ou 2ème essai.
  • Horaires réguliers (08:00 - 18:30).
  • Adresses IP connues ou géographiquement logiques.

02. SSH Brute Force

Contexte & Comportement

Un script automatisé (ex: Hydra) tente de deviner le mot de passe du compte root via le port 22. Le comportement réseau se traduit par un pic soudain de milliers de paquets TCP SYN/ACK suivis de fermetures immédiates de session (Fail).

Détection Wazuh (Layer 1)

10 Rule 5503 — SSH brute force attack
Seuil : > 50 failures / 30sec

Validation Machine Learning (Layer 2)

87/100 Confidence: 96%
Features activées : Vélocité anormale, Heure hors-bureau (01:00 AM).
Attaque — T1190

03. SQL Injection (WAF)

Contexte & Comportement

Un attaquant tente de bypasser le formulaire d'authentification sur une application web exposée en injectant un payload SQL tautologique ' OR 1=1 --. L'événement est capté par les logs Apache/Nginx.

Attaque — T1498

04. ICMP Flood (DDoS)

Contexte & Comportement

Saturation de la bande passante du pare-feu avec un volume massif de requêtes ping (ICMP Echo Request). L'objectif est de refuser le service aux utilisateurs légitimes. Taux dépassant allègrement la capacité du réseau.

Détection Wazuh (Layer 1)

9 Rule 100001 — ICMP flood detected
Seuil : > 10,000 pps (Packets per second)

Validation Machine Learning (Layer 2)

74/100 Confidence: 89%
Features activées : Volume absolu de trafic réseau anormale, Saturation interface.
Reconnaissance — T1046

05. Network Port Scan

Contexte & Comportement

Un adversaire map la topologie du réseau et les services ouverts à l'aide d'outils comme Nmap. Il envoie des paquets TCP furtifs (Stealth Scan) sur tous les ports allant de 1 à 1024 pour scruter les réponses (Open, Closed, Filtered).

Détection Wazuh (Layer 1)

7 Rule 100002 — Port scan detected
Seuil : > 20 ports distincts en 5 secondes.

Validation Machine Learning (Layer 2)

62/100 Confidence: 84%
Features activées : Incrémentation séquentielle de ports cibles.
